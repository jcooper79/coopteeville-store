# Coopteeville Store

A funny car-tee storefront hosted on Cloudflare Workers. Checkout runs on Stripe and orders are fulfilled through Printful.

- `public/`: the storefront (one animated page, inline SVG characters) and the logo
- `src/index.ts`: API for checkout, the Stripe webhook that creates the Printful order, and Pit Lane votes
- `src/catalog.ts`: server-side prices and Printful variant mapping
- `migrations/`: D1 schema
- `docs/STRATEGY.md`: differentiation, traffic plan, and vendor recommendations
- `docs/BRAND.md`: logo, palette, type, voice, and IP guardrails
- `docs/PRINT-SPECS.md`: print file spec for designers (sizes, DPI, format, checklist)
- `scripts/check-print-file.mjs`: pre-flight checker, `npm run check:print -- file.png`
- `docs/MARKET.md`: nearest competition, differentiation, market check
- `docs/TEAM.md`: the crew (Product Picker, Designers, Fulfillment, Customer Happiness)
- `docs/PRODUCTS.md`: trading cards, stickers, air fresheners and other product partners
- `docs/sale-map.html`: visual sale map (generated by `scripts/gen-sale-map.cjs`)
- `docs/ROADMAP.md`: what's next

## Run locally
```bash
npm install
cp .dev.vars.example .dev.vars   # fill in Stripe test keys
npm run db:migrate:local
npm run dev
```

## Deploy (first time)
```bash
npm run db:create          # paste the database_id into wrangler.jsonc
npm run db:migrate
npx wrangler secret put STRIPE_SECRET_KEY
npx wrangler secret put STRIPE_WEBHOOK_SECRET
npx wrangler secret put PRINTFUL_API_KEY
npx wrangler secret put VOTE_SALT
npx wrangler secret put PRINTFUL_WEBHOOK_TOKEN
npx wrangler secret put RESEND_API_KEY
npm run deploy
```
Then register two webhooks:
- Stripe: `https://<domain>/api/webhooks/stripe` for `checkout.session.completed`
- Printful (Settings > Webhooks or the API): `https://<domain>/api/webhooks/printful?token=<PRINTFUL_WEBHOOK_TOKEN>` for `package_shipped`, `order_failed`, `order_put_hold`, `order_canceled`

Turn on Stripe's email receipts (Settings > Emails) so customers get a receipt right after paying.

CI and other machines need `CLOUDFLARE_API_TOKEN` (permissions: Workers Scripts Edit, D1 Edit, Workers Routes Edit) and `CLOUDFLARE_ACCOUNT_ID`.

## Order flow (hands-off on the normal path)
1. The cart is posted to `/api/checkout`. The Worker re-prices it from `catalog.ts`, saves it to D1, and creates a Stripe Checkout Session.
2. Stripe calls `/api/webhooks/stripe`. The Worker verifies the signature, records the order once (idempotent), and sends it to Printful **confirmed**, so it goes straight into production.
3. Printful calls `/api/webhooks/printful` when the package ships. The Worker saves tracking and emails the customer through Resend.
4. Only exceptions need a person: plate orders while `PLATE_AUTO_APPROVE=false` (they wait as Printful drafts, status `needs_review`), Printful failures or holds (status `error`), refunds, and misprint reprints. See the Sale Map page for the full picture.
